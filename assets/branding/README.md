# bestOS 字标素材

从 `build_bootanimation.py` 第二屏的同一套参数直接出图，不是截图裁切，透明通道干净。

## 规格（与开机动画完全一致）

| 项 | 值 |
|---|---|
| 字体 | SF Pro Rounded / Heavy（可变字体实例） |
| 占宽 | 画布宽的 70%（原动画 1080 画布 → 756 px） |
| 填充 | 竖直渐变 `#92979C` → `#6C7176`（上亮下暗） |
| 四色条 | 宽度 = 字标宽 × 0.371，高 = 字标宽 × 0.00926，四段留 3px 缝 |
| 四色 | 蓝 `#4285F4` / 红 `#EA4335` / 黄 `#FBBC05` / 绿 `#52A883` |
| 落款 | 「马特提供系统」站酷快乐体，Y = 画布高 × 0.918 |

## 重新生成

```bash
cd bestOS项目/字标
~/.cache/bestos-build/.venv/bin/python 生成字标.py
```

改 `MARK_TOP` / `MARK_BOT` 换渐变，改 `mark_asset()` 的 `0.70` 换占宽，`mono=(r,g,b)` 出单色版。
