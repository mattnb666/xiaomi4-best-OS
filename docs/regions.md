# bestOS 系统地区

## 用户要求

- 首次开机引导和系统设置仅提供：中国大陆、香港、美国。
- 与四种界面语言独立选择；繁体中文（台湾）仍为语言选项，不因此增加台湾地区选项。
- 第三方软件不得修改系统地区等受保护的全局区域设置。

## 设计

- 系统地区允许值：CN、HK、US；默认 CN（暂定）。
- 仅 bestOS 首次引导与设置可在用户明确操作后修改。
- 保存独立的 bestOS 地区配置，不把语言 Locale 的地区子标签当作用户地区。必须保留 zh-TW 翻译选择能力。
- 系统全局语言、地区及由其派生的格式配置使用受保护的系统写入接口；读接口可供应用使用。
- 在系统服务端校验调用者身份、允许值和权限，不只隐藏界面入口。第三方应用不能凭广播、公开设置项或未受保护的组件写入。
- 不给第三方软件授予 CHANGE_CONFIGURATION、WRITE_SECURE_SETTINGS 等用于更改相关系统配置的权限。审查预装 Google、MT 和 Magisk 管理应用实际权限及调用路径。
- SIM、网络检测及账号同步不覆盖用户选择的地区。语言、时区、SIM/APN 分别管理；本需求不意味着伪造定位、IP 或运营商归属。
- 应用自己的账号国家、内容地区和应用内语言不等同于系统地区，不能承诺仅靠此配置统一第三方服务地区。

## Root 边界

普通第三方应用，包括未经 root 授权的 MT，必须无法修改受保护配置。用户授予 root、通过 root shell 或重刷系统后，不可能保证同样的绝对防修改约束。保留 Magisk 逐应用授权，不默许第三方自动获得 root。

## 状态与验证

当前仅完成规格，未实现地区选择页面或系统服务权限拦截。不能把三项地区值直接覆盖四项 supported_locales，否则会错误删除台湾繁体语言能力。

需验证四语言 × 三地区共 12 种组合、重启持久化、普通应用越权写入被拒绝、预装应用和同步不覆盖选择。地区格式如何映射到 Android 10 全局 Configuration 需要结合实际框架实现验证。
