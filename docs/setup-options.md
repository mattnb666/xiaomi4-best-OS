# 首次引导：基础选项、隐私与免责声明

## 流程

语言 → 地区 → 本地基础设置 → 隐私设置 → 免责声明 → 确认安装所选组件（如有）→ 完成/进入桌面。

游戏选择是基础设置的子页面，确认后保存选择并进入隐私设置。此处“激活”指完成本地引导，不是在线或账号激活。

## 本地基础设置

### 个性化广告

- 用户期望开启后允许 Google 相关推广信息，关闭后隐藏这些内容。默认关闭（设计默认值）。
- 在实际组件中逐项确定可控制的推广通知频道、bestOS 推荐入口及应用公开设置；关闭时屏蔽已识别的推广通知与本系统推荐入口。
- 不能将此开关描述成能控制所有 Google 应用内部广告、服务端个性化或所有“垃圾信息”；保留登录、安全、下载更新等必要通知。
- 开启只允许可控推广入口，不自动订阅推广，不代表用户同意全部 Google 数据收集条款。不以修改第三方 APK 或破坏签名实现。

### 预装玩机工具箱

- 开启后选择安装用户提供的 root 模块与配套软件；关闭不安装可选工具包，不移除已确认的基础 MT 管理器和 Magisk。
- 用户要求配套软件出厂具备 root：待具体 APK 核验包名和签名后，在引导确认中明确列出可预授权的工具应用；绝不使用“所有应用自动授权 root”的全局策略。
- 已确认组件可以在引导内自动安装，但启动开关不立即执行未知 ZIP。先显示组件名称、版本、修改范围与 root 授权范围，完成隐私告知和安装确认再执行。

### 游戏模块

- 入口点击后进入独立页面，标题“选择你想玩的游戏：”。
- 选项按顺序：三角洲、和平精英、王者荣耀、其他；暂按单选设计，允许不选择/跳过。
- 确认后根据选择关联对应组件，随后进入隐私设置；三角洲、和平精英、王者荣耀关联对应模块与软件，“其他”仅关联模块，不关联或安装软件。不因点击一个游戏名称立刻执行安装脚本。
- “其他”表示其他游戏，选择后仅安装用户提供的对应游戏模块，不添加任何配套 APK，也不默认安装所有模块。具体模块文件仍待用户提供。
- 当前对话没有提供任何游戏模块、工具箱模块或配套 APK。不得虚构文件路径、兼容性或安装成功状态。
- 游戏项仅表示用户的安装分组，不据名称推定附件用途或游戏在小米 4 上的运行表现。

## 隐私设置

- 展示本地保存、Google 服务的可选账号、推广开关、可选工具 root 权限等实际行为。
- 可选权限按功能区分，不用一次同意代替所有 Android 运行时权限。
- 已规划的锁屏防盗拍照仍默认关闭，提供单独说明与开启入口。

## 免责声明

- 明确这是小米 4 LTE 的定制系统，root/模块可能影响稳定性、隐私和第三方应用兼容性。
- 列出所选第三方组件与来源；不把免责声明当作免除责任、绕过许可或强制接受不相关条款的手段。
- 提供返回修改选项和继续按钮；无可选组件时可直接完成引导。

## 安装与恢复

- 仅安装经审查、校验且与实际 Alpha/内核版本兼容的本地附件，记录哈希与版本；执行前验证 root 后端就绪。
- 模块不等同于分区镜像刷写；安装方案须检查脚本实际写入范围。涉及 boot 等关键分区的附件单独处理，不直接执行未知安装器。
- 安装进度、失败原因、重试与跳过需可见；不得将失败标记成功。需要重启时保存引导状态，重启后继续。
- 避免重复安装，保留可恢复记录及模块停用路径；关闭选项不会静默删除用户原有组件。

## 当前状态

仅规格，尚未实现页面、通知过滤、模块安装器或 root 预授权。待用户提供附件和对应关系后才能核验并实现安装配置。
