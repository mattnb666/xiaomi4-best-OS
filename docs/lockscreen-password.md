# 数字密码与防盗拍照

文档核对日期：2026-10-25。项目总体状态见 [README](../README.md)。

## 用户需求

- 密码界面参考用户描述的魅族体验，同一数字选择控件支持滑动选择和点击选择数字。
- 连续输入错误两次后调用前置摄像头拍照，触发时不额外弹出提示。
- 未指定具体魅族版本或参考界面，不声称已经复刻其行为。

## 初版交互设计（待界面验证）

- 数字 PIN 输入提供 0–9 控件，同时支持滑动和点击：滑动定位数字后通过确认按钮输入，直接点击数字则输入该数字；两种操作共用同一密码输入框，不需切换模式。
- 区分拖动与点击，滑动松手不再触发点击输入；一次点击仅输入一位，不把滑动经过的每个数字自动输入。提供确认当前数字、删除和提交按钮。
- 已输入位置使用圆点隐藏；保留普通数字键盘切换和无障碍操作，以免滑动难以精确输入。
- 只有提交完整密码并得到系统凭据验证失败才计一次；滑动、删除或未完成输入不计错。
- 使用 Android LockSettings/GateKeeper 验证与失败节流，不另存明文密码或以自定义比较代替系统验证。

## 防盗拍照约束

- 默认关闭；机主在已解锁设置中明确开启，说明触发条件、相机使用及本地照片保存。锁屏说明中提供此功能已启用的可见告知。
- 连续两次验证失败后拍一次；同一失败序列不逐次重复拍照。成功验证密码后重置；避免通过锁屏重进或服务重启轻易绕过计数。
- 触发时不额外弹窗，不绕过平台相机隐私提示，不实现隐蔽监控或远程上传。
- 前摄占用、不可用、权限不足时跳过并记录本地错误，不阻塞解锁、不绕过密码锁定。
- 照片保存在系统功能专用私有目录，不暴露给媒体库；查看和删除需再次验证密码，默认最多保留最近 10 张（设计默认值）。
- 开机尚未首次解锁时受加密存储与相机初始化限制，需单独验证，未确认前不承诺拍照；不得为拍照降低设备加密保护。
- Root 授权应用可能访问系统数据，不能承诺对 root 隔离照片。
