# 本机名称与设备型号

## 用户规则

- 允许用户在 bestOS 设置中修改本机名称。
- 设备型号保持真实的小米 4 LTE 身份，普通第三方应用不能修改。
- 常规运行时权限、存储权限等不授予修改型号的能力；用户明确授予 root 的应用属于例外。

## 实现约束

- 将可编辑的显示名称与只读的设备身份分开；修改名称不得改写 ro.product.model、ro.product.device、品牌、制造商或构建指纹。
- 真实型号字段以验证过的目标设备配置为准，不为 bestOS 品牌或 Google 认证伪造其他型号。bestOS 名称与版本使用独立系统字段。
- 设备名称入口由系统设置提供，持久保存用户选择；蓝牙名称与本机名称是否联动需在实际系统实现中明确，不能假定修改所有无线标识。
- 保留 Android 系统属性和 SELinux 的权限约束，不暴露允许普通应用改写型号的接口，不为此授予特权权限。
- 本机名称可编辑不代表所有第三方应用都可任意改名；本条授权的是用户在设置中的操作。
- root 由用户逐应用批准；获准 root 的应用可能修改系统或伪装应用看到的型号，但不能改变物理硬件本身。

## 状态与验证

当前仅完成规则，尚未接入完整设备源码。后续验证修改名称和重启保存、型号保持不变，以及普通应用不能写入设备身份字段；root 例外不作为默认自动授权。
