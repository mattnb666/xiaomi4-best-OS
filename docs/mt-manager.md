## 已实现

APK 原样复制到 `vendor/bestos/prebuilt/MTManager/MTManager.apk`，Android.mk 声明 PRESIGNED 系统应用模块，common.mk 加入产品软件清单。没有使用平台密钥重新签名，也不授予平台签名权限或默认 root。

## 接入完整源码后必须完成

1. 移除其他独立文件管理器的产品预装项，包括 Google Files；保留 DocumentsUI/Storage Access Framework 系统文件选择能力，必要时仅隐藏其独立桌面入口。
2. 在系统包管理层按准确包名实施普通用户卸载/停用限制，同时允许签名兼容、版本合法的覆盖更新。只隐藏卸载按钮或预装到只读分区不等于完成此要求；需覆盖按用户卸载与 ADB 路径，不使用全局禁止安装策略。
3. 保留系统内置基线版本，用户更新安装在数据分区；恢复出厂后回到内置版本。默认允许卸载更新以回退基线，不能删除应用本身。
4. 更新必须匹配共存版包名、兼容签名和版本规则。普通版 MT 不一定可覆盖本共存版。尚未验证该 APK 内置更新渠道是否提供匹配包。
5. 用 apksigner 验证输入与构建输出，比较签名并实测首次启动、文件访问、更新、回退、卸载/停用拦截和恢复出厂。

“不可删除”的目标限于正常系统权限边界，不承诺抵抗 root 修改或重新刷写系统。当前只有预装构建配置，卸载保护尚未实现，未生成可刷机产物。
