# bestOS 全面定制范围

文档核对日期：2026-10-25。项目总体状态见 [README](../README.md)。

## 已确认方向

用户已选择完全独立的设计，并确认保留基础应用：电话、联系人、短信、相机、图库、文件管理、时钟、计算器、录音机、中文输入法。在此基础上增加 Google 服务、Play 商店和常用 Google 应用，详见 `google-apps.md`。

Android 10 是底层基础。桌面、系统界面、自带软件、设置和配置都属于定制范围，不以原生外观或仅更换名称为完成标准。保留已确认的电话、短信、蜂窝数据、Wi-Fi、蓝牙；默认竖屏，无 OTA 云更新。

全面定制不要求重写所有 Android 服务。保留所需的兼容性、安全与硬件服务，在源码可修改的界面和功能层实现 bestOS 设计。第三方闭源驱动不能据此假定可以任意修改。

## 模块清单（待逐项确定设计）

文件管理器已确定使用用户提供的 MT 管理器共存版，保留其自身界面及签名，不再开发或预装其他独立文件管理器；详见 `mt-manager.md`。

| 模块 | 定制内容 | 需要确定 |
| --- | --- | --- |
| 视觉规范 | 配色、字体、图标、间距、动画、明暗主题 | 风格参考及主要配色 |
| 桌面 | 首页、文件夹、应用列表、小组件、搜索 | 抽屉或全部应用放桌面、首页布局 |
| 系统界面 | 锁屏、状态栏、通知、快捷开关、音量与电源菜单、最近任务 | 导航方式、交互及信息密度 |
| 设置 | 分组、搜索、网络、显示、声音、电池、存储、权限、关于 bestOS | 新增功能与默认值 |
| 通信应用 | 电话、联系人、短信 | 页面设计、必需功能 |
| 常用应用 | 相机、图库、文件管理、时钟、计算器、录音、日历、音乐 | 预装清单及定制优先级 |
| 输入与浏览 | 中文输入法、浏览器、WebView | 应用选择、许可、离线能力 |
| 系统体验 | 开机动画、首次设置、壁纸、铃声、USB 行为、应用安装 | 资源与默认行为 |

以上是范围清单，不代表应用已经实现或确定全部预装。保留 Android 权限、签名和系统安全机制；相机及通信能力以底层适配验证为准。

## 制作顺序

1. 确定视觉方向、主要用途和预装软件清单，优先设计桌面、快捷设置及设置首页。
2. 确认可编译的 Android 10 / cancro 硬件适配及 Linux 构建环境。
3. 将确定的设计实现到 Launcher、SystemUI、Settings 与系统应用源码，逐模块验证。
4. 联调通信、媒体、权限与休眠，测量系统体积，生成和验证 MiFlash 包。

## 当前状态

仅有初始品牌与资源配置，没有定制应用、完整系统源码或可刷机镜像。界面风格、应用清单及特殊功能尚未确定。
